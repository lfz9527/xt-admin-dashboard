# 用户详情测试按钮设计

## 目标

在用户管理页面增加“查询用户详情”测试按钮，用于快速验证用户详情嵌套路由、菜单高亮和面包屑关联。

## 行为

- 用户点击“查询用户详情”按钮后，前端生成一个随机数字 ID。
- 页面跳转到 `/system/users/:id`。
- 继续使用现有用户详情路由和 `<Outlet />` 渲染链路。
- 不新增接口、全局状态或持久化数据。
- 按钮只用于当前测试页面，不新增用户列表和额外业务交互。

## 实现方式

在 `src/pages/system/users/index.tsx` 中使用 React Router 的 `useNavigate`，按钮点击时生成随机 ID，并导航到对应详情地址。随机 ID 使用现有浏览器运行环境可用的 `Math.random` 生成，不要求稳定值。

## 验收标准

- 页面显示“查询用户详情”按钮。
- 点击按钮后 URL 匹配 `/system/users/<数字>`。
- 详情页面可以正常显示。
- 用户管理菜单保持高亮，面包屑包含用户 ID。
- 测试覆盖按钮点击和导航行为。
- 相关测试、TypeScript 检查和 lint 通过。
