# NavTab 左右滚动按钮设计

## 目标

当导航 Tab 横向内容溢出时，在 Tab 区域两侧显示始终占位的左右滚动按钮；按钮在对应滚动边界禁用，点击后平滑滚动内容。无溢出时不显示按钮，也不增加 Tab 区域高度。

## 方案

继续使用现有 `ScrollArea` 作为横向滚动容器，并扩展其 viewport ref 能力，让 `NavTab` 能够读取滚动节点并监听 `scroll` 事件。`NavTab` 自己负责按钮布局、边界状态和滚动操作。

按钮使用 `lucide-react` 的 `ChevronLeft` 与 `ChevronRight`：

- 有横向溢出时显示左右按钮；无溢出时不渲染按钮。
- 左右按钮始终保留各自位置；左端禁用左按钮，右端禁用右按钮。
- 点击按钮以 viewport 宽度为步长执行 `scrollBy({ left, behavior: 'smooth' })`。
- 监听 viewport 的滚动和尺寸变化，更新 `canScrollLeft`、`canScrollRight`。
- 激活 Tab 的 `scrollIntoView` 保持不变，随后由滚动事件同步按钮状态。
- 原生横向滚动条继续隐藏，不增加 `padding-bottom`。

## 边界行为

- 没有横向溢出：左右按钮都不显示。
- 有横向溢出且 `scrollLeft=0`：左按钮禁用，右按钮可用。
- 有横向溢出且到达最大滚动距离：左按钮可用，右按钮禁用。
- 中间滚动位置：左右按钮均可用。
- 快速连续点击由浏览器平滑滚动处理，状态通过 scroll 事件更新。
- 不改变现有 Tab 点击、关闭、pill 高亮和自动定位行为。

## 验证

- 测试无溢出时不显示按钮。
- 测试有溢出时显示左右按钮，初始左禁用、右可用。
- 测试点击左右按钮调用对应方向的平滑滚动。
- 测试滚动到边界后按钮禁用状态同步更新。
- 运行 NavTab 相关测试、`pnpm lint` 和 `pnpm build`。
