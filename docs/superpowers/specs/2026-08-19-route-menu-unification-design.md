# 路由与菜单统一配置设计

## 1. 背景与目标

当前路由和菜单分别维护，导致菜单路径、路由页面、菜单高亮和面包屑可能出现不一致。用户详情路由缺少菜单关联，角色详情路由缺少有效的 Outlet 渲染链路，菜单状态持久化也可能保留过期配置。

本次采用“路由配置生成菜单”的方案：路由配置作为唯一业务导航源，菜单和面包屑从路由树派生，并预留权限过滤能力。

目标：

- 路由、菜单和面包屑共享标题、路径、菜单标识等配置。
- 菜单点击路径始终对应实际路由。
- 动态详情页可以高亮所属列表菜单。
- 用户详情和角色详情采用嵌套路由，详情内容替换列表内容。
- 权限过滤可以同时作用于路由和菜单，暂时不绑定具体后端权限接口。
- 菜单不再作为独立持久化状态保存。

## 2. 配置模型

扩展 `RouteMeta`，支持以下导航字段：

- `title`：页面或菜单标题。
- `menuKey`：菜单关联标识，同一菜单下的详情路由可以复用列表页的 `menuKey`。
- `icon`：菜单图标名称，仅菜单节点需要。
- `showInMenu`：是否生成侧边菜单项；详情路由默认为不显示或显式设置为 `false`。
- `permission`：预留的权限标识，可为单个权限码或权限码数组，具体格式由后续权限接入确定。

路由树中的布局路由和详情路由可以拥有页面渲染配置，但只有带有菜单元数据的路由参与菜单派生。父级菜单作为路由树中的目录节点表达，不为目录节点重复维护独立菜单对象。

## 3. 路由与页面层级

保留现有业务 URL，并调整详情页为列表路由的嵌套路由：

- `/system/users`
  - `/system/users/:id`
- `/system/roles`
  - `/system/roles/detail`

列表父页面需要渲染 `<Outlet />`，使详情路由能够替换列表内容。详情路由不显示为侧边菜单项，但通过 `menuKey` 关联所属菜单，以支持菜单高亮和面包屑。

用户详情路由加载用户详情页面模块，而不是用户列表模块。

## 4. 菜单派生与权限过滤

新增纯函数/工具，将布局下的路由树转换为 `MenuItem[]`：

1. 过滤不参与菜单的路由（没有 `menuKey` 或 `showInMenu === false`）。
2. 对每个菜单节点执行权限判断。
3. 递归处理子路由。
4. 父子权限都校验：父级自身无权限时隐藏，即使子级有权限；父级有权限但没有可见子级时也不生成空目录。
5. 只保留有可见菜单节点的目录。
6. 使用路由的 `path`、`title`、`menuKey` 和 `icon` 生成菜单项。

权限判断抽象为独立函数或过滤器，当前使用允许全部访问的默认实现。后续接入权限码时，只需替换权限上下文或判断函数，同时用于构建可访问路由和菜单，不改动菜单组件的渲染逻辑。

路由过滤应在 `buildRouter` 阶段执行；菜单过滤使用同一套判断规则。若未来权限数据异步获取，需要在权限状态准备完成后再构建应用路由和菜单，避免菜单与路由使用不同权限快照。

## 5. 高亮与面包屑

- `Menus` 从当前匹配路由的 `handle.menuKey` 获取高亮标识。
- 详情路由显式设置所属菜单的 `menuKey`，不再依赖 pathname 回退猜测。
- 菜单树和面包屑使用同一份派生菜单数据。
- 目录节点没有独立可访问路径时，面包屑目录项不生成错误链接。
- 动态路径尾段仍作为详情页面的文本面包屑展示。

## 6. 状态管理

删除菜单树在 `useMenu` 中的独立 `mockMenus` 状态和 `app-menu` 持久化。菜单是路由配置与权限状态的派生数据，不应被 localStorage 缓存。

侧边栏开关状态可以继续保留现有 store；如需持久化，应与菜单数据分离，避免路由配置变更后恢复旧菜单树。

## 7. 测试与验收

新增或更新测试覆盖：

- 路由元数据可以派生出正确的菜单层级、标题、路径和图标。
- `showInMenu: false` 的详情路由不出现在菜单中。
- 详情路由的 `menuKey` 能使所属菜单保持高亮。
- 父级无权限时，子菜单不会单独残留。
- 父级有权限但所有子级无权限时，不生成空目录。
- 用户详情和角色详情可以通过父页面 Outlet 正确渲染。
- 菜单和面包屑使用统一配置。
- 动态详情 URL 的面包屑包含动态段且列表菜单项可回退访问。

验证命令：

- `pnpm test`
- `pnpm lint`
- `pnpm build`

## 8. 范围边界

本次不实现具体后端权限接口、不确定权限码格式，也不新增权限管理页面。只提供稳定的权限字段和过滤边界，保证后续接入权限数据时可以同时过滤路由与菜单。
